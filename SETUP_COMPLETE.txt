🧠 HOW IT WORKS - ReAct PATTERN

The agent follows a reasoning + acting loop:

  1. THINK
     Grok LLM generates reasoning about the query

  2. ACT
     Execute an appropriate tool:
     • calculator (math operations)
     • search (information retrieval)
     • web_fetch (URL content)

  3. OBSERVE
     Process the tool output

  4. REPEAT
     Until final answer is ready
